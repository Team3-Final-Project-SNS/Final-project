# 관리자 유저 관리 정책

## 적용 대상

이 문서는 관리자 콘솔의 유저 목록 조회, 계정 상태 확인, 계정 정지 안내에 사용한다.

## 유저 목록 기능

- 관리자는 학교별 유저 목록을 확인할 수 있다.
- 관리자는 유저의 기본 정보와 계정 상태를 확인할 수 있다.
- 유저 상태는 ACTIVE, SUSPENDED, WITHDRAWN 등 서비스 상태에 따라 구분될 수 있다.

## 계정 정지 정책

- 계정 정지는 회원 탈퇴와 다르다.
- 정지된 유저는 서비스 이용이 제한된다.
- 정지된 유저는 같은 이메일로 재가입이 차단될 수 있다.
- 계정 정지는 신고 채택 누적 제재 정책을 참고한다.

## 신고 채택 누적 제재

| 채택 누적 횟수 | 제재 |
| --- | --- |
| 1회 | 경고 |
| 2회 | 경고 |
| 3회 | 3일 정지 |
| 4회 | 10일 정지 |
| 5회 | 30일 정지 |
| 6회 이상 | 영구 정지 |

## 관리자 처리 원칙

- 관리자는 유저 정지 사유를 확인하고 처리해야 한다.
- 신고 채택 누적, 게시글 삭제 이력, 노쇼 이력, 고객 문의 이력을 함께 확인할 수 있다.
- AI는 계정 정지를 직접 실행하지 않는다.
- AI는 누적 신고와 정책을 바탕으로 관리자 검토 필요 여부를 안내한다.

## 개인정보 보호

- AI는 비밀번호, 토큰, 인증번호를 출력하지 않는다.
- AI는 필요한 최소한의 유저 상태만 안내한다.
- 민감한 개인정보는 관리자 화면의 권한 범위 안에서만 확인한다.

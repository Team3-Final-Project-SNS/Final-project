# 관리자 주문 결제 관리 정책

## 적용 대상

이 문서는 관리자 콘솔의 주문 결제 관리, 포인트 충전 검증, 환불 안내, 결제 장애 대응에 사용한다.

## 주문 결제 관리 기능

- 관리자는 결제 내역과 주문 상태를 확인할 수 있다.
- 관리자는 결제 금액, 충전 패키지, merchant_uid, imp_uid, 결제 상태를 확인할 수 있다.
- 결제 이상 건은 PortOne 검증 결과와 서버 DB 상태를 함께 확인해야 한다.

## 포인트 충전 흐름

1. 서버에서 merchant_uid와 결제 금액을 READY 상태로 먼저 저장한다.
2. 프론트엔드에서 PortOne SDK 결제를 호출한다.
3. 결제 완료 후 프론트엔드는 imp_uid를 서버로 전달한다.
4. 서버는 PortOne API를 직접 호출해 실제 결제 금액을 검증한다.
5. 선택한 패키지 금액과 PortOne 실제 결제 금액이 일치할 때만 포인트를 지급한다.

## 충전 패키지

- 1P는 1원 기준이다.
- 기본 충전 패키지는 3,000P, 5,000P, 10,000P, 20,000P다.
- 자유 입력 충전과 패키지 충전을 함께 지원할 수 있다.

## 무료 포인트와 유료 포인트

- 무료 포인트는 가입 보너스, 신고 포상, 후기 보상 등으로 지급된다.
- 유료 포인트는 현금 결제 충전으로 지급된다.
- 사용자 화면에는 무료 포인트와 유료 포인트의 합산 잔액을 보여준다.
- 내부 DB에서는 free_point와 paid_point를 분리 관리한다.

## 차감 순서

- 게시글 작성 또는 매칭 신청으로 포인트를 사용할 때는 무료 포인트를 먼저 차감한다.
- 무료 포인트가 충분하면 무료 포인트에서만 차감한다.
- 무료 포인트가 부족하면 무료 포인트를 전액 차감하고 부족분을 유료 포인트에서 차감한다.

## 환불 정책

- 현금 환불은 유료 포인트에 대해서만 가능하다.
- 가입 보너스와 신고 포상 같은 무료 포인트는 환불할 수 없다.
- 환불은 1,000원 단위로만 가능하다.
- 이미 사용한 포인트가 있으면 사용분을 제외하고 환불한다.
- PortOne 결제 취소는 결제 후 당일만 가능한 경우가 많으므로, 상황에 따라 결제 취소가 아닌 잔여 유료 포인트 환불로 처리한다.

## 결제 장애 대응

- 결제는 완료되었으나 포인트가 반영되지 않았다면 PortOne 결제 상태와 서버 거래 내역을 함께 확인한다.
- 네트워크 지연으로 결제 신호 반영이 늦어질 수 있다.
- AI는 환불이나 포인트 지급을 직접 실행하지 않는다.
- AI는 결제 상태 확인 방법과 관리자 검토 필요 여부를 안내한다.

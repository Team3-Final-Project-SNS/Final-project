# 관리자 고객 문의 및 FAQ 관리 정책

## 적용 대상

이 문서는 관리자 콘솔의 고객 문의 관리, FAQ 관리, 고객센터 답변 템플릿 안내에 사용한다.

## 고객 문의 관리 기능

- 관리자는 고객 문의를 확인하고 답변할 수 있다.
- 문의에 관리자가 답변하면 해당 문의는 종료된다.
- 답변 완료 후 문의는 삭제할 수 없다.
- 문의 삭제는 답변 전 상태에서만 가능하다.
- 문의 상태가 PENDING 또는 READ일 때만 삭제할 수 있다.

## 고객 문의 제한

- 고객은 하루 최대 20회까지 문의를 접수할 수 있다.
- 문의는 1분 간격을 두고 접수할 수 있다.
- 이 제한은 반복 문의와 스팸성 문의를 줄이기 위한 정책이다.

## FAQ 관리 기능

- FAQ는 자주 묻는 질문과 안내 문구를 관리하는 기능이다.
- 관리자는 서비스 정책, 이용 방법, 결제, 신고, 매칭, 계정 관련 FAQ를 관리할 수 있다.
- FAQ 문구는 고객센터 답변 품질을 일정하게 유지하기 위한 기준 자료로 사용한다.

## 문의 카테고리

| 카테고리 | 주요 문의 유형 |
| --- | --- |
| ACCOUNT | 계정, 인증, 로그인 |
| PAYMENT | 결제, 포인트, 환불 |
| USAGE | 이용 방법, 기능 사용 |
| HISTORY | 이용 내역, 과거 매칭, 영수증 |
| MATCH | 매칭 오류, 장소 인증, GPS 장애 |
| REPORT | 신고, 노쇼, 불량 이용 |

## 답변 템플릿 원칙

- 고객 문의 답변은 정중한 한국어로 작성한다.
- 실제 상황에 맞는 원인 설명과 해결 조치를 포함한다.
- 개인정보나 민감 정보는 노출하지 않는다.
- 결제, 환불, 계정 제재, 신고 처리처럼 확인이 필요한 문제는 관리자 확인 결과를 바탕으로 답변한다.
- AI는 답변 초안을 만들 수 있지만, 최종 답변 등록은 관리자가 수행한다.

## ACCOUNT 답변 방향

- 계정 인증 실패, 로그인 문제, 기기 변경, 계정 복구 문의에 사용한다.
- 본인 명의 휴대폰, 가입 이메일, 인증 정보 일치 여부를 확인하도록 안내한다.
- 추가 확인이 필요하면 오류 화면 캡처와 함께 재문의하도록 안내한다.

## PAYMENT 답변 방향

- 결제 완료 후 포인트 미반영, 잘못 결제한 환불 요청, 거래 내역 확인에 사용한다.
- 포인트 반영 지연은 네트워크 상태와 결제 신호 지연 가능성을 안내한다.
- 환불 가능 여부는 유료 포인트 잔액과 사용 이력을 확인한 뒤 안내한다.
- 결제 수단에 따라 취소 반영까지 영업일 기준 3~5일이 걸릴 수 있음을 안내한다.

## USAGE 답변 방향

- 앱 기능 사용법, 프로필 변경, 책임비 설정, 게시글 작성 방법에 사용한다.
- 앱 내 메뉴 이동 경로와 단계별 조치를 안내한다.
- 더 자세한 사용법은 FAQ 또는 이용 방법 화면을 안내한다.

## HISTORY 답변 방향

- 과거 매칭 내역, 결제 영수증, 이용 내역 확인 문의에 사용한다.
- 개인정보 보호와 데이터 보존 정책에 따라 일부 내역 제공이 제한될 수 있음을 안내한다.
- 필요한 경우 가입 이메일 또는 관리자 확인 절차를 안내한다.

## MATCH 답변 방향

- GPS 오류, 장소 인증 실패, QR 인증 실패, 매칭 프로세스 장애에 사용한다.
- 증빙자료와 시스템 로그를 교차 확인해야 한다.
- 정상 만남을 증빙할 수 있으면 관리자 권한으로 만남 인증 완료 처리를 검토할 수 있다.

## REPORT 답변 방향

- 노쇼, 부적절한 언행, 불량 이용, 신고 처리 문의에 사용한다.
- 신고 내용은 내부 운영 정책에 따라 조사한다고 안내한다.
- 특정 유저 처벌을 즉시 약속하지 않는다.
- 필요한 경우 닉네임, 채팅 기록, 캡처 등 추가 정보를 요청한다.

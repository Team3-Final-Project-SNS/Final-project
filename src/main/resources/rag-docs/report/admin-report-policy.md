# 관리자 신고 처리 정책

## 적용 대상

이 문서는 관리자 신고 AI가 신고 분석, 고위험 유저 탐지, 게시글 삭제, 신고 포상, 계정 제재 제안을 할 때 사용하는 정책이다.
AI 분석은 최종 처분이 아니라 관리자 의사결정을 돕는 참고 정보다.

## 신고 처리 원칙

- 신고 처리는 관리자 검토를 통해 채택 또는 기각한다.
- AI는 신고를 직접 채택하거나 기각하지 않는다.
- AI는 신고 원문, 대상 게시글, 신고자 정보, 피신고자 정보, 누적 신고 이력을 근거로 요약과 권고를 제공한다.
- 최종 처분은 관리자가 실제 신고 처리 API를 통해 결정한다.

## 동일 게시물 재신고 제한

- 악의적 신고를 막기 위해 동일 게시물 재신고를 제한한다.
- 기각된 게시물 신고에 대해 3일 이내 재신고할 수 없다.
- 단, 수정된 게시글에 한해서는 재신고가 가능하다.

## 신고 포상 정책

- 신고가 ACCEPTED 상태로 채택된 경우에만 신고자에게 50P 포상을 지급한다.
- REJECTED 상태로 기각된 신고에는 포상을 지급하지 않는다.
- 동일 유저의 월별 신고 포상은 최대 300P까지 지급한다.
- 신고 포상은 어뷰징 방지를 위해 월 한도를 적용한다.

## 신고 기능 제한

- 신고자의 기각 횟수가 3의 배수에 도달하면 해당 시점부터 10일간 신고 기능을 박탈한다.
- 신고 기능 제한은 채택된 신고와 무관하게 REJECTED 상태로 기각된 신고 건수만 기준으로 누적한다.
- 근거 부족 신고, 반복 신고, 악의적 신고를 줄이기 위한 정책이다.

## 신고된 게시글 상태

- 게시글이 신고 상태라면 매칭 신청을 제한할 수 있다.
- 신고된 게시글을 관리자가 삭제하면 신고 채택과 게시글 삭제가 함께 처리될 수 있다.
- 관리자가 게시물을 삭제하려고 할 때 해당 게시물에 대한 신고 건이 있으면 신고 채택 및 게시글 삭제 처리를 함께 고려한다.
- 신고 처리와 게시글 삭제가 동시에 이루어질 수 있으므로 동시성 제어가 필요하다.

## 게시글 강제 삭제

- 관리자는 정책 위반 게시글을 강제 삭제할 수 있다.
- 신고 대상 게시글이 아니더라도 관리자 판단으로 삭제할 수 있다.
- 게시글 강제 삭제 시 등록자 예치 포인트는 전액 환불한다.
- 게시글 삭제 사유는 작성자에게 알림으로 안내한다.
- 삭제 사유 상세 페이지를 통해 사용자가 사유를 확인할 수 있게 한다.

## 계정 제재 기준

작성한 게시글이 신고 채택으로 삭제 처리된 누적 횟수에 따라 제재를 적용한다.

| 채택 누적 횟수 | 제재 | 알림 메시지 |
| --- | --- | --- |
| 1회 | 경고 | 신고가 채택되었습니다. 서비스 이용 규정을 준수해 주세요. |
| 2회 | 경고 | 두 번째 경고입니다. 재발 시 계정이 정지될 수 있습니다. |
| 3회 | 3일 정지 | 세 번째 규정 위반으로 계정이 3일간 정지되었습니다. |
| 4회 | 10일 정지 | 네 번째 규정 위반으로 계정이 10일간 정지되었습니다. |
| 5회 | 30일 정지 | 다섯 번째 규정 위반으로 계정이 30일간 정지되었습니다. |
| 6회 이상 | 영구 정지 | 지속적인 규정 위반으로 계정이 영구 정지되었습니다. |

## 위험도 판단 기준

- LOW: 신고 상세가 부족하거나 정책 위반 근거가 약한 경우
- MEDIUM: 정책 위반 가능성이 있지만 추가 확인이 필요한 경우
- HIGH: 반복 신고, 채택 신고 누적, 명확한 위반 정황, 피해 가능성이 큰 경우

## AI 권고 기준

- ACCEPT 권고: 신고 내용과 대상 게시글, 누적 이력에서 정책 위반 근거가 충분한 경우
- REJECT 권고: 신고 근거가 부족하거나 중복, 악의적 신고 가능성이 큰 경우
- NEEDS_REVIEW 권고: 증빙 또는 맥락이 부족해 관리자가 추가 확인해야 하는 경우

## 관리자 권한

- 유저 목록 조회
- 유저 계정 정지
- 게시글 강제 삭제
- 신고 처리
- 이의제기 판정
- 고객 문의 답변

## 관리자 보안 정책

- 관리자 AccessToken은 일반 유저보다 짧은 15분으로 설정한다.
- 관리자는 RefreshToken 없이 재로그인을 강제할 수 있게 한다.
- 이 정책은 토큰 탈취 위험을 낮추기 위한 보안 정책이다.

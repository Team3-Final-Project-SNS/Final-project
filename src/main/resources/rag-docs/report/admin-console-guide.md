# 관리자 콘솔 운영 가이드

## 적용 대상

이 문서는 관리자 콘솔 AI가 관리자에게 화면 기능, 처리 흐름, 운영 정책을 안내할 때 사용하는 기준 문서다.
관리자 콘솔은 게시글 보기, 신고 관리, 고객 문의 관리, 유저 목록, 주문 결제 관리, FAQ 관리 기능을 제공한다.

## 관리자 콘솔 메뉴

| 메뉴 | 역할 |
| --- | --- |
| 게시글 보기 | 등록된 게시글 목록과 상세 내용을 확인한다. |
| 신고 관리 | 접수된 신고를 확인하고 채택 또는 기각 처리한다. |
| 고객 문의 관리 | 고객 문의를 확인하고 답변한다. |
| 유저 목록 | 학교별 유저 목록과 계정 상태를 확인한다. |
| 주문 결제 관리 | 결제 내역과 주문 상태를 관리한다. |
| FAQ | 자주 묻는 질문과 안내 문구를 관리한다. |

## 관리자 AI의 역할

- 관리자 AI는 운영자가 어떤 메뉴에서 어떤 작업을 해야 하는지 안내할 수 있다.
- 관리자 AI는 신고, 게시글, 유저, 결제, 문의, FAQ 정책을 요약할 수 있다.
- 관리자 AI는 실제 삭제, 정지, 환불, 신고 채택, 문의 답변 등록을 직접 실행하지 않는다.
- 관리자 AI의 답변은 운영 보조이며 최종 처리는 관리자 API와 화면 조작으로 수행한다.

## 권한 원칙

- 관리자 기능은 SUPER_ADMIN 권한을 가진 사용자만 사용할 수 있다.
- 일반 유저의 AccessToken은 30분이며, 관리자 AccessToken은 보안을 위해 15분이다.
- 관리자는 RefreshToken 없이 재로그인을 강제하는 구조를 사용한다.
- 관리자 토큰이 만료되면 다시 로그인해야 한다.

## 장애 격리 원칙

- AI 답변 생성이 실패해도 관리자 콘솔의 핵심 기능은 계속 동작해야 한다.
- AI가 실패하면 기존 관리자 목록 조회, 신고 처리, 게시글 삭제, 문의 답변 기능은 그대로 사용할 수 있어야 한다.
- AI는 실패 시 "직접 메뉴에서 확인해 주세요" 형식의 fallback 안내를 제공한다.

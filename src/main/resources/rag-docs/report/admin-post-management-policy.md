# 관리자 게시글 관리 정책

## 적용 대상

이 문서는 관리자 콘솔의 게시글 보기, 게시글 상세 확인, 게시글 강제 삭제, 신고 연계 삭제 안내에 사용한다.

## 게시글 보기 기능

- 관리자는 등록된 게시글 목록을 확인할 수 있다.
- 게시글 목록에서는 작성자, 학교, 장소, 만남 시간, 모집 상태, 신고 여부를 확인할 수 있다.
- 게시글 상세에서는 게시글 내용, 책임비, 모집 인원, 작성자 정보, 매칭 상태를 확인할 수 있다.

## 게시글 강제 삭제

- 관리자는 정책 위반 게시글을 강제 삭제할 수 있다.
- 삭제 사유는 관리자가 작성해야 한다.
- 삭제 사유는 작성자에게 알림으로 전달한다.
- 게시글 삭제 후 사용자는 삭제 사유 상세 페이지에서 사유를 확인할 수 있다.

## 신고 연계 삭제

- 삭제하려는 게시글에 신고 건이 있으면 관리자에게 신고 건 존재를 알려야 한다.
- 관리자는 신고 채택과 게시글 삭제를 함께 처리할 수 있다.
- 신고 채택과 게시글 삭제가 함께 처리되면 신고자 포상 지급과 게시글 삭제가 이어질 수 있다.
- 관리자와 신고 처리가 동시에 발생할 수 있으므로 동시성 제어가 필요하다.

## 포인트 처리

- 게시글 강제 삭제 시 등록자 예치 포인트는 전액 환불할 수 있다.
- 신고 당한 게시글이 삭제된 경우에도 등록자 예치 포인트 환불 정책을 확인해야 한다.
- AI는 포인트 환불을 직접 실행하지 않고 처리 기준만 안내한다.

## 매칭 제한

- 신고 상태인 게시글은 매칭 신청이 제한될 수 있다.
- 삭제된 게시글은 더 이상 매칭 신청 대상이 아니다.
- 매칭 취소 또는 게시글 삭제 후 채팅방은 정책에 따라 완전 비활성화될 수 있다.

## 관리자 AI 답변 원칙

- AI는 게시글 삭제 사유를 임의로 만들어내지 않는다.
- AI는 게시글 내용과 신고 정보가 Tool 또는 DB로 확인된 경우에만 구체적으로 설명한다.
- 정보가 부족하면 게시글 상세 화면 또는 신고 상세 화면 확인을 안내한다.

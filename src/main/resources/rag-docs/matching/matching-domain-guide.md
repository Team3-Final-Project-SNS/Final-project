# 매칭 AI 도메인 검색 가이드

## 적용 대상

이 문서는 매칭 AI가 사용자의 자연어 조건을 해석하고, 게시글과 사용자 데이터를 검색할 때 참고하는 도메인 정책이다.

## 매칭 가능한 게시글

- 같은 학교 사용자끼리 매칭한다.
- 모집 중인 OPEN 상태의 게시글만 추천 후보가 될 수 있다.
- 모집 인원이 가득 찬 게시글은 추천하지 않는다.
- 약속 시간이 지난 게시글은 추천하지 않는다.
- 사용자가 이미 신청한 게시글은 중복 추천하지 않는다.
- 사용자가 직접 작성한 게시글은 추천하지 않는다.
- 사용자의 보유 포인트가 책임비보다 부족하면 신청 가능한 후보로 추천하지 않는다.

## 게시글 정책

- 최소 모집 인원은 2명이다.
- 최대 모집 인원은 10명이다.
- 책임비는 최소 200P 이상이다.
- 책임비는 작성자의 보유 포인트 한도 안에서 설정한다.
- 책임비는 매칭 신청자에게도 동일하게 차감된다.

## 자연어 조건 해석

매칭 AI는 사용자의 표현을 다음 검색 조건으로 해석할 수 있다.

| 사용자 표현 | 해석 예시 |
| --- | --- |
| 오늘 밥 먹을 사람 | meetAt이 오늘인 게시글 |
| 저녁에 먹을 사람 | 저녁 시간대 게시글 |
| 조용하게 먹고 싶어 | 게시글 내용, 장소, 후기에서 조용함과 관련된 후보 |
| 많이 먹는 메뉴 뭐야 | 메뉴, 장소, 게시글 내용, 후기에서 자주 언급되는 음식 |
| 매너온도 높은 사람 | 작성자의 매너온도 또는 후기 평균이 좋은 후보 |
| 책임비 낮은 곳 | 책임비가 낮은 게시글 |

## RAG와 Tool Calling 역할 분리

- RAG는 사용자의 자연어 의미와 가까운 게시글, 장소, 메뉴, 후기 맥락을 찾는다.
- Tool Calling은 RAG가 찾은 후보가 현재 신청 가능한지 실시간 DB 기준으로 검증한다.
- RAG 검색 결과만으로 신청 가능 여부를 확정하지 않는다.
- 최종 추천 전에는 게시글 상태, 정원, 약속 시간, 사용자의 포인트, 중복 신청 여부를 Tool로 확인한다.

## 추천 답변 원칙

- 존재하지 않는 게시글, 메뉴, 장소, 사용자를 만들어내지 않는다.
- 후보가 없으면 조건을 넓히도록 안내한다.
- 신청 불가 후보는 신청 불가 사유를 함께 설명한다.
- 매칭 신청이나 포인트 차감은 AI가 직접 실행하지 않는다.

## 매너온도 활용

- 매너온도 기본값은 36.5도다.
- 후기를 기반으로 실시간 평균 집계한다.
- 매너온도는 좋은 만남 경험의 참고 지표로 사용할 수 있다.
- 매너온도가 높다는 이유만으로 무조건 추천하지 않고, 시간, 장소, 모집 상태, 포인트 조건도 함께 확인한다.

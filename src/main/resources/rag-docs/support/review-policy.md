# 한끼팟 후기 및 매너온도 정책

## 적용 대상

이 문서는 후기 작성 조건, 후기 수정과 삭제, 후기 태그, 신고 연계, 매너온도 반영에 대한 고객 안내에 사용한다.

## 후기 작성 조건

- 후기는 매칭 상태가 COMPLETED인 경우에만 작성할 수 있다.
- 후기 작성 가능 기간은 만남 완료 시점부터 7일 이내다.
- 7일이 지나면 후기 작성 버튼은 비활성화된다.

## 1:1 만남 후기

- 1:1 만남에서는 신청자가 만남에 대한 후기를 작성할 수 있다.

## 1:N 만남 후기

- 1:N 만남에서는 신청자들이 만남 자체에 대한 후기를 작성한다.
- 신청자들끼리는 서로 후기를 작성하지 않는다.
- 작성된 후기는 만남을 주선한 등록자의 매너온도에 반영된다.
- 여러 신청자가 동시에 평가해도 개별 점수의 단순 합산이 아니라 해당 만남의 평균 점수를 기준으로 등록자의 매너온도에 반영한다.

## 후기 수정 및 삭제

- 후기는 한 번 작성하면 수정할 수 없다.
- 후기는 한 번 작성하면 삭제할 수 없다.
- 후기는 만남 이후의 경험을 기록하는 데이터이므로 작성 시점의 평가를 그대로 보존한다.

## 후기 태그 정책

- 후기 작성 시 사용자는 `좋았어요` 또는 `아쉬웠어요` 중 하나의 방향을 선택한다.
- 좋았어요 태그와 아쉬웠어요 태그는 동시에 선택할 수 없다.
- 각 방향에는 최대 5개의 태그가 존재한다.

## 좋았어요 태그 예시

- 시간 약속을 잘 지켰어요.
- 대화 코드가 잘 맞았어요.
- 부담 없이 편하게 밥 먹는 분위기였어요.
- 식사 매너가 좋았어요.
- 다음에 또 한 끼 같이하고 싶어요.

## 아쉬웠어요 태그 예시

- 약속 시간에 늦었어요
- 소통이 잘 안 되고 조금 어수선했어요
- 생각했던 만남과 성격이 달랐어요
- 식사 매너가 아쉬웠어요
- 다시 만나고 싶지 않아요

## 신고 연계 정책

- 아쉬웠어요 태그 중 `다시 만나고 싶지 않아요`를 선택하면 상호 블라인드 처리한다.
- 상호 블라인드 처리된 사용자는 이후 서로 매칭되지 않도록 제한한다.
- 후기 자체가 곧바로 신고 채택이나 계정 제재로 이어지지는 않는다.
- 별도 제재가 필요하면 신고 접수 절차를 안내한다.

## 매너온도 반영 정책

- 매너온도는 작성된 후기들의 점수를 기반으로 만남 단위의 평균 변화량을 계산하여 누적 반영한다.
- 매너온도 최저값은 0도다.
- 매너온도 최고값은 99도다.
- 매너온도 기본값은 36.5도다.
- 계산식은 `매너온도 = 현재 매너온도 + (새로운 모임 평균 점수 - 이전 모임 평균 점수) * 0.5` 형태를 따른다.
- 매너온도는 소수점 첫째 자리로 반올림하여 표기한다.

## 매너 점수 산정 방식

- 좋았어요 태그는 선택 개수가 많을수록 높은 점수로 반영하되 최대 +2점을 넘지 못한다.
- 아쉬웠어요 태그는 선택 개수가 많을수록 낮은 점수로 반영하되 최소 -3점보다 낮아지지 않는다.
- 한 명의 신청자가 줄 수 있는 점수는 -3점부터 +2점 사이로 제한한다.
- 선택 개수를 그대로 노출하지 않도록 최대/최소 제한을 적용한다.

| 선택 예시 | 점수 |
| --- | --- |
| 좋았어요 태그 1개 선택 | +1점 |
| 좋았어요 태그 2개 선택 | +2점 |
| 좋았어요 태그 3개 이상 선택 | +2점 |
| 아쉬웠어요 태그 1개 선택 | -1점 |
| 아쉬웠어요 태그 2개 선택 | -2점 |
| 아쉬웠어요 태그 3개 선택 | -3점 |
| 아쉬웠어요 태그 4개 이상 선택 | -3점 |

## 탈퇴 유저의 후기

- 탈퇴한 유저에게 작성된 후기는 삭제하지 않는다.
- 화면에는 탈퇴한 유저 정보를 `알 수 없음`으로 표시한다.
- 1:N 만남에서는 신청자들이 작성한 후기를 기반으로 등록자의 매너온도를 반영한다.

## 후기 조회 정책

- 사용자는 내가 작성한 후기만 조회할 수 있다.
- 사용자는 내 매칭 조회 화면에서 `내가 작성한 후기 보기` 버튼을 통해 후기를 조회할 수 있다.

## 후기 작성 알림

- 만남 인증 완료 후 2시간이 지나 채팅방이 읽기 전용으로 전환될 때 후기 작성 알림을 발송한다.
- 알림 예시: `만남이 완료되었습니다. 후기를 작성해주세요!`
- 후기 작성 가능 기간 마지막 날에도 알림을 발송한다.
- 알림 예시: `오늘이 후기를 작성할 수 있는 마지막 날입니다. 서둘러 작성해주세요!`

## 사용자 안내 원칙

- AI는 후기를 대신 작성하거나 삭제하지 않는다.
- AI는 후기 작성 가능 조건과 기간, 태그 정책을 안내한다.
- 신고 연계가 필요한 경우 신고 접수 절차를 안내한다.

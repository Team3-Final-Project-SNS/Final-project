# 한끼팟 채팅 및 알림 정책

## 적용 대상

이 문서는 그룹채팅, 채팅방 비활성화, 메시지 조회, 알림 보존과 SSE 알림에 대한 고객 안내에 사용한다.

## 채팅방 생성

- 첫 번째 신청자가 매칭을 신청하면 채팅방이 즉시 생성된다.
- 게시글 작성자는 HOST 역할로 채팅방에 입장한다.
- 신청자는 GUEST 역할로 채팅방에 입장한다.
- 한끼팟은 1:1 채팅과 그룹 채팅을 지원한다.
- 정원이 모두 차면 더 이상 신청할 수 없다.

## 채팅방 참여 흐름

- 신청자가 신청 즉시 채팅방에 입장한다.
- 신청자가 1명이면 HOST와 GUEST 1명으로 총 2명이 채팅방에 참여한다.
- 신청자가 2명이면 HOST와 GUEST 2명으로 총 3명이 채팅방에 참여한다.
- 정원이 모두 차면 게시글은 추가 신청을 받을 수 없다.

## 참여자 권한

- 채팅방 참여자만 메시지를 전송하고 조회할 수 있다.
- 참여자가 아닌 사용자가 접근하면 CHAT_NOT_PARTICIPANT 에러를 반환한다.
- HOST는 게시글 작성자이고, GUEST는 신청자다.

## 메시지 전송

- 매칭됨 상태인 사용자만 채팅 메시지를 보낼 수 있다.
- 비활성화된 채팅방은 읽기만 가능하고 메시지 전송은 제한된다.
- 욕설이 포함된 메시지는 `***`로 자동 마스킹될 수 있다.

## 읽기 전용 비활성화

- 만남 완료 시 채팅방은 2시간 후 읽기 전용으로 전환된다.
- 노쇼 예정 시 채팅방은 즉시 읽기 전용으로 전환된다.
- 노쇼 확정 시 채팅방은 즉시 읽기 전용으로 전환된다.
- 읽기 전용 상태에서는 메시지 전송이 불가능하지만 메시지 조회는 가능하다.
- 읽기 전용 상태는 복구할 수 없다.

## 완전 비활성화

- 1:1 매칭 취소 시 채팅방은 즉시 완전 비활성화된다.
- 매칭 취소 후 OPEN된 게시글이 삭제되면 채팅방은 즉시 완전 비활성화된다.
- HOST가 매칭을 취소하면 채팅방은 즉시 완전 비활성화된다.
- 완전 비활성화 상태에서는 메시지 조회도 제한된다.
- HOST 취소 시 모든 GUEST는 강제 퇴장하고 모든 GUEST 예치 포인트는 100% 반환한다.
- HOST 취소 시 HOST 예치 포인트는 50% 몰수하고 게시글은 CANCELLED 상태로 전환한다.

## 그룹 채팅 개인 퇴장

- 그룹 채팅방에서 GUEST가 매칭을 취소하면 해당 유저만 ChatMember에서 제거된다.
- 퇴장한 유저는 채팅방 접근이 제한된다.
- 해당 유저의 예치 포인트는 50% 몰수된다.
- 채팅방은 HOST와 남은 GUEST가 계속 이용한다.
- 게시글은 OPEN 상태가 되어 재신청이 가능할 수 있다.
- 퇴장한 유저가 채팅방에 접근하면 CHAT_NOT_PARTICIPANT 에러가 발생한다.

## 메시지 조회

- 메시지는 커서 기반 페이징으로 조회한다.
- 최신순 기준으로 조회한다.
- 한 번에 최대 20개 메시지를 조회할 수 있다.
- 읽기 전용 상태에서는 비활성화 후에도 조회가 가능하다.
- 완전 비활성화 상태에서는 조회가 불가능할 수 있다.

## 알림 보존 정책

- 알림 보존 기간은 10일이다.
- 10일이 지난 알림은 스케줄러가 자동 삭제한다.
- 알림은 한 번에 50개씩 커서 기반 스크롤로 조회한다.
- 종 모양 버튼을 누르면 알림 목록을 조회할 수 있다.
- 전체 읽음 버튼으로 알림을 일괄 읽음 처리할 수 있다.

## 알림 장애 격리

- 알림은 비동기로 처리한다.
- 알림 전송이 실패해도 핵심 서비스 로직은 정상 처리되어야 한다.
- 정상 종료, 타임아웃, 에러 상황에서도 다른 로직은 계속 정상 동작한다.
- SSE 이미터 연결 타임아웃은 30분을 기준으로 한다.
- 타임아웃 시 이미터 연결을 끊어 같은 알림이 중복 전송되지 않도록 한다.

## 사용자 안내 원칙

- AI는 채팅방 상태를 직접 변경하지 않는다.
- AI는 알림 삭제나 읽음 처리를 직접 실행하지 않는다.
- AI는 정책과 사용 방법을 안내하고 실제 처리는 앱 기능으로 연결한다.

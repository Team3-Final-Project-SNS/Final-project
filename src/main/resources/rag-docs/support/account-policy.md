# 한끼팟 계정 및 관리자 정책

## 적용 대상

이 문서는 회원가입, 계정 제한, 관리자 권한, 고객 문의 운영에 대한 고객센터 답변 근거로 사용한다.

## 회원가입 정책

- 한끼팟은 학교 이메일 기반 가입을 사용한다.
- 학교 이메일은 `.ac.kr` 도메인을 기준으로 한다.
- 한 이메일당 하나의 계정만 만들 수 있다.
- 회원가입 시 서비스 약관과 안전 수칙에 동의한다.

## 계정 정지 정책

- 계정 정지는 회원 탈퇴와 다른 개념이다.
- 정지된 계정은 서비스 이용이 제한된다.
- 정지된 사용자는 같은 이메일로 재가입이 차단될 수 있다.
- 계정 정지 조건은 신고 채택 누적 제재 정책을 따른다.

## 관리자 보안 정책

- 일반 유저 AccessToken 유효 시간은 30분이다.
- 관리자 AccessToken 유효 시간은 보안을 위해 15분으로 더 짧게 설정한다.
- 관리자는 RefreshToken 없이 재로그인을 강제하는 구조를 사용한다.
- 이 구조는 토큰 탈취 위험을 낮추기 위한 보안 정책이다.

## 관리자 권한

| 작업 | SUPER 관리자 |
| --- | --- |
| 유저 목록 조회 | 가능 |
| 유저 계정 정지 | 가능 |
| 게시글 강제 삭제 | 가능 |
| 신고 처리 | 가능 |
| 이의제기 판정 | 가능 |
| 고객 문의 답변 | 가능 |

## 관리자 업무 범위

- 관리자는 정책과 관련된 운영 조치를 처리한다.
- 유저 계정 정지는 신고 채택 누적 제재 정책을 참고한다.
- 게시글 삭제 시 관리자는 삭제 사유를 작성하고 글쓴이에게 알림으로 안내한다.
- 신고 처리에서 채택 시 신고자에게 50P를 지급하고, 기각 시 반려 처리한다.
- 이의제기 최종 판정은 증빙자료와 사유를 바탕으로 관리자가 판단한다.
- 고객 문의 답변은 문의 타입에 따라 템플릿을 활용할 수 있다.

## 고객 문의 정책

- 문의 삭제는 답변 전 상태에서만 가능하다.
- 문의 상태가 PENDING 또는 READ인 경우에만 삭제할 수 있다.
- 답변 완료 후에는 문의를 삭제할 수 없다.
- 문의에 관리자가 답변하면 해당 문의는 종료된다.
- 고객은 하루 최대 20회까지 문의를 접수할 수 있다.
- 문의는 1분 간격을 두고 접수할 수 있다.

## 사용자 안내 원칙

- AI는 계정 정지, 관리자 권한 실행, 문의 삭제를 직접 처리하지 않는다.
- AI는 사용자의 계정 상태를 조회할 수 있는 Tool 결과가 있을 때만 개인 상태를 안내한다.
- 보안상 비밀번호, 토큰, 인증번호, 내부 설정값은 안내하지 않는다.

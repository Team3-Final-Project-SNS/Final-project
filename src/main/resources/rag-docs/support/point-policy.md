# 한끼팟 포인트 정책

## 적용 대상

이 문서는 한끼팟 사용자의 포인트 지급, 예치, 반환, 차감, 충전, 환불 안내에 사용한다.
고객센터 AI는 포인트 관련 질문에 답할 때 이 문서를 우선 근거로 사용한다.

## 기본 포인트

- 회원가입 시 사용자에게 10,000P 가입 보너스를 지급한다.
- 가입 보너스 포인트는 무료 포인트로 취급하며 현금 환불 대상이 아니다.
- 사용자에게 보이는 잔액은 무료 포인트와 유료 포인트의 합산 금액이다.

## 책임비 예치

- 게시글 작성 시 책임비를 예치한다.
- 매칭 신청 시 게시글 등록자가 설정한 책임비와 동일한 포인트를 신청자에게서 차감한다.
- 책임비는 최소 200P 이상이어야 한다.
- 책임비는 사용자의 보유 포인트 한도 안에서 자율 설정한다.
- 정책상 예치 포인트는 100P 단위로 증감하는 것이 원칙이다.
- 잔액이 부족하면 게시글 작성 또는 매칭 신청이 불가능하며, 포인트 충전으로 안내한다.

## 정상 완료 반환

- 만남이 정상 완료되면 예치 포인트는 100% 반환된다.
- GPS 장소 인증과 QR 만남 인증이 완료되면 만남 완료로 처리한다.

## 매칭 취소 반환

- 1:1 매칭 취소 시 취소한 사람의 예치 포인트는 50% 몰수하고 상대방 예치 포인트는 100% 반환한다.
- 1:1 매칭에서 등록자가 취소하면 게시글은 CANCELLED 상태로 전환한다.
- 1:N 매칭에서 신청자가 취소하면 해당 신청자의 예치 포인트만 50% 몰수하고 나머지 신청자와 모임은 유지한다.
- 1:N 매칭에서 신청자가 취소하면 해당 신청자만 채팅방에서 퇴장하고 게시글은 OPEN 상태를 유지할 수 있다.
- 1:N 매칭에서 등록자가 취소하면 모든 신청자의 예치 포인트는 100% 반환하고 등록자의 예치 포인트는 50% 몰수한다.
- 1:N 매칭에서 등록자가 취소하면 모든 신청자는 강제 퇴장하고 게시글은 CANCELLED 상태로 전환한다.
- 약속 시간이 지난 뒤에는 일반 취소가 제한될 수 있으며 장소 인증, QR 인증, 노쇼 정책에 따라 처리한다.

## 노쇼 차감

- 노쇼로 최종 확정되면 예치 포인트는 전체 차감된다.
- 노쇼 예정 상태가 된 뒤 24시간 이내 이의제기가 없으면 노쇼로 최종 판정한다.
- 이의제기가 수용되면 예치금 100% 반환, 부분 수용되면 50% 반환, 반려되면 몰수 상태를 유지한다.

## 신고 포상

- 신고가 관리자에 의해 채택되면 신고자에게 50P 포상을 지급한다.
- 신고가 기각되면 포상 포인트는 지급하지 않는다.
- 동일 유저의 신고 포상은 월 최대 300P까지 지급한다.
- 신고 포상은 무료 포인트로 취급한다.

## 무료 포인트와 유료 포인트 사용 순서

- 포인트를 사용할 때는 무료 포인트를 먼저 차감한다.
- 무료 포인트가 부족하면 무료 포인트 전액 차감 후 부족분을 유료 포인트에서 차감한다.
- 유료 포인트와 무료 포인트는 내부적으로 분리 관리하지만 사용자 화면에는 합산 잔액을 보여준다.

## 환불 정책

- 현금 환불은 유료 포인트에 대해서만 가능하다.
- 무료 포인트, 가입 보너스, 신고 포상은 현금 환불 대상이 아니다.
- 환불은 1,000원 단위로만 가능하다.
- 이미 사용한 포인트가 있으면 사용분을 제외하고 환불한다.
- PortOne 결제 취소는 결제 후 당일만 가능한 경우가 많으므로, 사용 이력이 있으면 결제 취소가 아닌 잔여 유료 포인트 환불로 처리할 수 있다.

## 충전 패키지

- 1P는 1원 기준으로 취급한다.
- 기본 충전 패키지는 3,000P, 5,000P, 10,000P, 20,000P다.
- 서버는 결제 요청 전에 merchant_uid와 결제 금액을 READY 상태로 저장한다.
- 프론트는 PortOne SDK로 결제를 진행한다.
- 결제 완료 후 imp_uid를 서버로 전달한다.
- 서버는 PortOne API를 직접 호출해 실제 결제 금액을 검증한다.
- 사용자가 선택한 패키지 금액과 PortOne 실제 결제 금액이 일치할 때만 포인트를 지급한다.

## 사용자 안내 원칙

- AI는 포인트 지급, 환불, 결제 취소를 직접 실행하지 않는다.
- 결제 오류, 예외 환불, 포인트 반영 지연은 1:1 문의 또는 관리자 확인으로 안내한다.
- 포인트가 반영되지 않은 경우 네트워크 지연 가능성을 안내하고 재접속을 권장한다.
- 개인 결제 내역 확인이 필요한 경우 실시간 Tool 또는 관리자 문의로 안내한다.
